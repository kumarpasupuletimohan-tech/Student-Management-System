
 Overview:

The Student Management System is a web-based application developed using ASP.NET Core MVC that helps manage student records efficiently.
The system allows users to create, view, update, and delete student information stored in a database.

This project demonstrates practical implementation of:

MVC architecture

CRUD operations

Database integration

Entity Framework Core ORM



Features:
Add new students,View student list,Edit student details,Delete student records,Database integration with SQL Server,Clean MVC architecture

Technologies Used :
                        
C#	                                 (Backend programming),
ASP.NET Core MVC	                   (Web framework),
Entity Framework Core              	(ORM for database interaction),
Microsoft SQL Server	               (Database),
HTML / CSS / Razor	                 (Frontend views),
Microsoft Visual Studio (Development environment)
